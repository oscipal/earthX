Hier liegen die projektweiten Skills, die jede Cloud-Sitzung automatisch sieht.

**Stand 19.09.2026: leer, und das ist so entschieden.** Ottos drei Skills
(`atomic-commits`, `code-cleanup`, `readme-updater`) bleiben vorerst in seiner
persönlichen Claude-Code-Umgebung und werden nicht hierher kopiert
(`docs/KLAERUNGEN.md` B14, Zeile vom 19.09.2026 im Entscheidungslog).

`CLAUDE.md` nicht mehr auf die Skills, sondern nennt die Regel selbst: kleine,
thematisch getrennte Commits mit aussagekräftiger Nachricht; vor dem PR die
geänderten Dateien aufräumen.
